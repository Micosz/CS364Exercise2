# ระบบตรวจจับการเขย่าและนับแยกตามรอบกิจกรรม

Related to #2

## ขอบเขตตาม Checklist

- **ข้อ 2 Shake Detection**: ใช้ Accelerometer (`Sensor.TYPE_ACCELEROMETER`) ตรวจจับการเขย่าอย่างเป็นจังหวะ และนับจำนวนครั้งที่เกิดขึ้นอย่างสมเหตุสมผล
- **ส่วนการเขย่าของข้อ 3 Session Delta**: เริ่มรอบใหม่ที่ 0 และนับเฉพาะการเขย่าที่เกิดขึ้นภายในรอบนั้น โดยการเขย่านอกรอบหรือก่อนกดเริ่มไม่เพิ่มยอด

## การทำงานและอัลกอริทึม

### 1. การคำนวณแรงความเร่ง ($g$)
`ShakeDetector` ลงทะเบียนรับข้อมูลความเร่ง 3 แกน ($X, Y, Z$) จาก `Sensor.TYPE_ACCELEROMETER` ด้วยอัตราเร็ว `SENSOR_DELAY_GAME` เพื่อให้จับจุดพีคของการเขย่าได้ทัน แล้วคำนวณขนาดความเร่งรวมเทียบกับแรงโน้มถ่วงของโลก ($g$):

$$g = \frac{\sqrt{x^2 + y^2 + z^2}}{\text{SensorManager.GRAVITY\_EARTH}}$$

เมื่อวางเครื่องนิ่งบนโต๊ะ ขนาดแรงรวมจะอยู่ที่ประมาณ $1.0g$

### 2. เกณฑ์การตัดสินจังหวะเขย่า (Hysteresis & Debounce)
เพื่อแยกการเขย่าตั้งใจออกจากการเคลื่อนไหวทั่วไปและป้องกันการนับเบิ้ล มีการใช้เกณฑ์ 4 ประการร่วมกัน:

| ค่าในโค้ด | ค่าที่ใช้ | หน้าที่และการทำงาน |
|---|---|---|
| `TRIGGER_G` | 2.25 | ระดับความเร่งขั้นต่ำที่จะเริ่มพิจารณานับเป็นการเขย่า ป้องกันการขยับปกติหรือเดินก้าวเท้า ($< 2.0g$) |
| `RELEASE_G` | 1.35 | สัญญาณต้องลดต่ำลงมาใกล้แรงโน้มถ่วงปกติก่อน จึงจะพร้อมรับการเขย่าครั้งถัดไป (`armed = true`) |
| `MIN_GAP_NS` | 500,000,000 | เว้นระยะห่างขั้นต่ำ 0.5 วินาทีระหว่างครั้ง ป้องกัน sample ในระลอกเดียวกันหรือการสะท้อนกลับ (rebound) ทำให้นับซ้ำ |
| `armed` | boolean flag | ตัวล็อกสถานะ เมื่อแตะ `TRIGGER_G` แล้วจะปลดเป็น `false` ทันที และจะพร้อมใหม่เมื่อผ่าน `RELEASE_G` เท่านั้น |

### 3. การแยกรอบกิจกรรม (Session Delta)
- เมื่อกด **"เริ่มกิจกรรม"** (`startRound()`): เรียก `setRound(true, 0)` จะรีเซ็ต `count = 0`, ตั้ง `armed = true`, กำหนด `lastShake = -MIN_GAP_NS` และบันทึกเวลา `roundStart` ทำให้เริ่มนับใหม่ที่ 0 ทันที และคัดกรองข้อมูลค้างคิวในเซนเซอร์ก่อนเริ่มรอบทิ้งไป
- เมื่อกด **"จบและบันทึกกิจกรรม"** (`saveRound()`): เรียก `setRound(false, count)` ปรับ `active = false` การเขย่าหลังจากนี้จะไม่ถูกนำไปบวกเพิ่มในรอบเดิม
- เมื่อเปิดแอปค้างไว้หรือกดสลับหน้าจอ (`onPause()` / `onResume()`): แอปจะหยุดฟังเซนเซอร์ใน `pause()` เพื่อประหยัดแบตเตอรี่ และเริ่มฟังต่อใน `resume()` โดยคงค่ายอดนับเดิมไว้ครบถ้วน

### 4. กรณีอุปกรณ์ไม่มีเซนเซอร์
หากเปิดบนอุปกรณ์ที่ไม่มี Accelerometer เมธอด `status()` จะคืนข้อความ `"เครื่องนี้ไม่มีเซนเซอร์ตรวจจับการเขย่า"` โดยแอปไม่หยุดทำงาน (no crash)

## วิธีทดสอบบนมือถือ

1. เปิดโปรเจกต์ใน Android Studio ใช้ Gradle JDK 21 และ Android SDK 37 (compileSdk 37, minSdk 26)
2. Run บนมือถือจริง Android 8.0 ขึ้นไป
3. กด **"เริ่มกิจกรรม"** แล้วทดลองเขย่าเป็นจังหวะ โดยเว้นอย่างน้อย 1 วินาทีระหว่างครั้ง
4. ตรวจสอบว่ายอดเพิ่มทีละ 1 จนครบตามจำนวนจริง
5. ทดสอบวางนิ่ง ถือเดินตามปกติ สลับแอป และกดเริ่มรอบใหม่เพื่อดูยอดรีเซ็ตเป็น 0

## ตรวจบนเครื่อง

```bash
.\gradlew.bat --no-daemon testDebugUnitTest assembleDebug
```

Unit tests ใน `ShakeDetectorTest` ตรวจสอบความถูกต้องครอบคลุม:
1. การเขย่าเป็นจังหวะ 5 ครั้ง เว้น 1 วินาที เพิ่มทีละ 1 จนได้ 5
2. การเขย่าครั้งเดียวที่มีหลาย sample ติดกัน นับเพียง 1 ครั้ง
3. การแกว่งกลับ (rebound) ภายใน 500 ms ไม่ถูกนับซ้ำ
4. การวางเครื่องนิ่งที่แรงโน้มถ่วง 1.0g นาน 15 วินาที ยอดคงเป็น 0
5. การเคลื่อนไหวปกติ (เดิน/หยิบเครื่อง ที่แรง $1.1g - 1.9g$) ยอดไม่เพิ่ม
6. การเขย่าขณะอยู่นอกรอบ (`active = false`) ไม่เพิ่มยอด
7. การเริ่มรอบใหม่ ยอดรีเซ็ตเป็น 0 และยอดรอบเดิมคงเดิม
8. ข้อมูลที่เวลาเก่ากว่าเวลาเริ่มรอบ (`timestamp < roundStart`) ถูกคัดกรองทิ้ง
9. การกู้คืนรอบกิจกรรมคงค่ายอดเดิมและนับต่อได้ถูกต้อง
10. การรายงานสถานะเมื่อไม่มีเซนเซอร์และแอปไม่ล้ม
