# 02-shake-detection

กดเริ่ม เขย่าหนึ่งครั้ง หยุด แล้วเขย่าอีกครั้ง หน้าจอควรแสดง 2 ครั้ง จากนั้นจบรอบและเริ่มรอบใหม่ ตัวเลขเริ่มที่ 0 จุดปรับความไวและระยะห่างระหว่างครั้งอยู่ใน ShakeDetector.java ควรลองทั้งตอนวางนิ่ง เดินปกติ และเขย่าจริง

เปิดโฟลเดอร์ StepByStep ใน Android Studio และ Sync ก่อน Run โมดูล app เมื่อทดสอบแล้วใช้ `git status -sb` ตรวจว่าอยู่บน `feature/shake-detection` แล้ว `git push -u origin HEAD` เพื่อเปิด PR เข้า main
