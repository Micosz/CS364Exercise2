# ระบบนับก้าวแยกตามรอบกิจกรรม

Related to #1

## ขอบเขตตาม Checklist

- ข้อ 1 Step Counter Sensor: ใช้ `TYPE_STEP_COUNTER` และแสดงจำนวนก้าวที่ตรวจจับได้
- ส่วนก้าวเดินของข้อ 3 Session Delta: เริ่มรอบใหม่ที่ 0 และคำนวณเฉพาะผลต่างของรอบนั้น

## การทำงาน

`StepCounterManager` ตรวจสิทธิ์ `ACTIVITY_RECOGNITION` และความพร้อมของเซนเซอร์
ก่อนลงทะเบียน listener และรับค่าฐานไว้ขณะเปิดแอป การเริ่มรอบใหม่จะเก็บ
ค่าก้าวสะสมล่าสุดไว้เป็นฐาน โดยไม่ยกเลิกและลงทะเบียน listener ใหม่
ค่าระหว่างรอบจะอัปเดตฐานแต่ไม่เพิ่มยอดของกิจกรรมที่จบแล้ว

`StepSessionCounter` ใช้ค่าครั้งแรกเป็นฐาน เช่น 4,200 ก้าว แล้วเมื่อได้รับค่า
4,217 จะแสดง 17 ก้าวของรอบปัจจุบัน โดยไม่แสดงยอดสะสมตั้งแต่เปิดเครื่อง
ข้อมูลเริ่มต้นจากเซนเซอร์แบบ on-change อาจมีเวลาเก่าขณะยืนนิ่ง จึงยอมรับเป็นฐาน
แต่ไม่นับเป็นก้าวใหม่ ข้อมูลที่เรียงตามเวลาแต่เกิดก่อนเริ่มรอบและเพิ่งส่งมาถึง
จะอัปเดตฐานโดยไม่เพิ่มยอด ส่วนข้อมูลซ้ำหรือย้อนลำดับจะถูกละทิ้ง
เพื่อไม่ให้นับก้าวซ้ำ และเก็บผลต่างของข้อมูลหลังเริ่มรอบไว้ครบ

เมื่อสลับไปแอปอื่น จะหยุดฟังและเก็บยอดที่นับแล้วไว้ เมื่อกลับมาจะตั้งฐานใหม่
เพื่อไม่นำก้าวระหว่างออกจากแอปเข้ามารวม การให้สิทธิ์จะเริ่มฟังเมื่อ Activity
อยู่ด้านหน้า โดยไม่ขึ้นกับว่า permission dialog คืน window focus แล้วหรือยัง

## วิธีทดสอบบนมือถือ

1. เปิดโปรเจกต์ใน Android Studio ใช้ Android SDK 37 และ Gradle JDK ของ Android Studio
2. Run บนมือถือ Android 8.0 / API 26 ขึ้นไปที่มี Step Counter
3. กดเริ่มเพื่อขอสิทธิ์หากยังไม่ได้อนุญาต หลังอนุญาตให้รอค่าฐานก่อนกดเริ่มอีกครั้ง
   หากเซนเซอร์ยังไม่ส่งค่าฐาน ลองเดินเตรียมเล็กน้อย แล้วรอข้อความสถานะหาย
4. กดเริ่มรอบ เปิดหน้าจอแอปค้างไว้ แล้วเดิน 15–20 ก้าว หยุดรอให้เซนเซอร์รายงานค่า
   ก่อนจบรอบ จดจำนวนที่เดินและยอดในแอป
5. จบรอบ เดินระหว่างรอบ แล้วกดเริ่มรอบใหม่ขณะยืนนิ่ง รอค่าตั้งต้นก่อนเดินชุดถัดไป
6. ทดลองปฏิเสธสิทธิ์ ให้สิทธิ์ภายหลัง และสลับแอปแล้วกลับมา

Step Counter มีความหน่วงในการรายงานได้ถึงประมาณ 10 วินาที ค่าสะสมเพียงอย่างเดียว
ไม่สามารถแยกแต่ละก้าวในข้อมูลก้อนเดียวที่คร่อมช่วงเริ่มกิจกรรมได้อย่างสมบูรณ์
จึงต้องรอค่าตั้งต้นก่อนเริ่มเดินและรอรายงานค่าก่อนจบรอบ โดยบันทึกความคลาดเคลื่อนจริง
ของเครื่องที่ใช้ ไม่สรุปว่าผ่านจากผล Build หรือ unit tests เพียงอย่างเดียว

## ตรวจบนเครื่อง

```bash
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

Unit tests ตรวจยอดสะสมครั้งแรก การนับหลังมีฐาน รอบใหม่ การเดินระหว่างรอบ
ข้อมูลเก่า/ซ้ำ/ย้อนลำดับ การกลับเข้าแอป การคืนยอดเดิม และกรณีเซนเซอร์รีเซ็ต

## ตรวจสอบเมื่อมือถือยังแสดง 0

- ถ้ามีข้อความว่าไม่มีเซนเซอร์: ต้องตรวจรุ่นเครื่องและความพร้อมของ TYPE_STEP_COUNTER
- ถ้ามีข้อความเรื่องสิทธิ์: อนุญาตกิจกรรมทางกายใน Settings ของแอป
- ถ้ารอค่าตั้งต้น: ยังไม่ได้รับค่าแรก ไม่เริ่มจับเวลาจนเซนเซอร์พร้อม
- ถ้าไม่มีข้อความสถานะ: โค้ดพบเซนเซอร์ ผ่านสิทธิ์ ลงทะเบียนสำเร็จ และมีค่าฐานแล้ว
  ให้ทดสอบขณะเปิดแอปไว้และรอการรายงานค่าหลังเดิน
- หากยังเป็น 0 ให้บันทึกรุ่นมือถือ Android เวอร์ชัน APK และ Logcat โดยกรอง tag `StepCounter`
  บันทึก `register=... sensor=...` และ `raw=... timestamp=...` ก่อนและหลังเดิน
  เพื่อแยกว่าเซนเซอร์ไม่ส่งข้อมูล ค่าสะสมไม่เพิ่ม หรือข้อมูลเพิ่มแล้วแต่ยอดในหน้าจอไม่เปลี่ยน
