# 01-step-counter

เริ่มรอบบนมือถือ Android ที่มี Step Counter อนุญาตการตรวจจับกิจกรรม รอจนค่าเริ่มต้นพร้อม แล้วลองเดิน 15–20 ก้าว หยุดสักครู่ให้เซนเซอร์รายงานค่า จากนั้นบันทึกรอบ เริ่มรอบที่สองขณะยืนอยู่กับที่ ยอดต้องเริ่มที่ศูนย์ การเดินก่อนกดเริ่มจะไม่ถูกนำมาเป็นยอดของรอบใหม่

ตัวนับใช้ค่าต่างของ TYPE_STEP_COUNTER และหยุดฟังเมื่อแอปไม่อยู่ด้านหน้า เมื่อกลับมาอ่านค่าตั้งต้นใหม่โดยเก็บจำนวนที่บันทึกได้แล้ว เครื่องที่ไม่มีเซนเซอร์หรือไม่ได้รับสิทธิ์จะแสดงสถานะบนหน้ากิจกรรม

เปิดโฟลเดอร์ StepByStep ใน Android Studio และ Sync ก่อน Run โมดูล app เมื่อทดสอบแล้วใช้ `git status -sb` ตรวจว่าอยู่บน `feature/step-counter` แล้ว `git push -u origin HEAD` เพื่อเปิด PR เข้า main

## รายการทดสอบที่ต้องบันทึกผลจริง

- [ ] Build และติดตั้งแอปได้
- [ ] อนุญาตสิทธิ์ รอค่าตั้งต้น แล้วเดิน 15–20 ก้าว พร้อมจดยอดที่แอปแสดง
- [ ] จบรอบและเริ่มรอบใหม่ขณะยืนนิ่ง ยอดเริ่มที่ 0
- [ ] เดินระหว่างรอบ แล้วยืนยันว่าก้าวก่อนเริ่มไม่ติดไปรอบใหม่
- [ ] ปฏิเสธสิทธิ์แล้วแอปไม่ล้ม และแสดงสถานะที่ถูกต้อง
- [ ] ให้สิทธิ์ภายหลัง แล้วกลับมานับก้าวได้
- [ ] สลับแอปแล้วกลับมา ยอดเดิมยังอยู่และไม่กระโดดเป็นยอดสะสม
- [ ] เครื่องที่ไม่มี Step Counter แสดงสถานะและไม่ล้ม หากไม่มีเครื่องให้ระบุว่ายังไม่ได้ทดสอบ
- [ ] ทดสอบร่วมกับฐานข้อมูล ประวัติ และสถิติหลังรวมส่วนที่เกี่ยวข้อง

จุดที่ต้องตรวจเป็นพิเศษคือค่าตั้งต้นและ event ที่รายงานล่าช้าตอนเริ่มรอบ
รวมถึงค่าครั้งแรกหลังได้รับสิทธิ์หรือกลับเข้าแอป ให้บันทึกอุปกรณ์ Android/API
จำนวนที่เดิน จำนวนที่แอปแสดง และภาพหรือวิดีโอ โดยไม่ทำเครื่องหมายผ่านก่อนทดสอบจริง
