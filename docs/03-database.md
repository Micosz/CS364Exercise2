# 03-database

เริ่มกิจกรรมแล้วจบและบันทึกสองรอบ เปิดแท็บประวัติเพื่อดูจำนวนรอบ ปิดแอปแล้วเปิดใหม่ จำนวนรอบยังคงอยู่ ใช้ Database Inspector เปิดฐาน step_by_step.db และตรวจคอลัมน์ของตาราง sessions การลบผ่านหน้ารายละเอียดทดสอบได้เมื่อรวม branch ประวัติแล้ว สถิติจะคำนวณจากรายการที่เหลือเมื่อรวม branch หน้าหลัก

เปิดโฟลเดอร์ StepByStep ใน Android Studio และ Sync ก่อน Run โมดูล app เมื่อทดสอบแล้วใช้ `git status -sb` ตรวจว่าอยู่บน `SQLite` แล้ว `git push -u origin HEAD` เพื่อเปิด PR เข้า main
