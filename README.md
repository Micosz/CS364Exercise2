## ความสามารถของแอป

- **นับก้าวเดิน** ด้วย `TYPE_STEP_COUNTER` โดยคำนวณผลต่างจากค่าก้าวสะสมของเซนเซอร์ให้เป็นจำนวนก้าวของรอบปัจจุบัน
- **ตรวจจับการเขย่า** ด้วย Accelerometer พร้อมป้องกันการนับซ้ำจากการเขย่าครั้งเดียว
- **แยกข้อมูลแต่ละรอบ** เริ่มจำนวนก้าวและการเขย่าที่ 0 เมื่อเริ่มกิจกรรมใหม่
- **จับเวลาและคำนวณค่าเฉลี่ย** แสดงระยะเวลาของรอบ ก้าวต่อนาที และจำนวนการเขย่าต่อนาที
- **สรุปยอดและสถิติ** แสดงยอดรวมจากกิจกรรมที่บันทึก ค่าสูงสุดต่อรอบ และป้าย `New Record` เมื่อรอบล่าสุดทำสถิติใหม่
- **บันทึกประวัติใน SQLite** เก็บเวลาเริ่ม ระยะเวลา จำนวนก้าว และจำนวนการเขย่า เปิดแอปใหม่แล้วยังดูรายการเดิมได้
- **ดูและจัดการประวัติ** แสดงรายการล่าสุดก่อน แตะเพื่อดูรายละเอียด และยืนยันก่อนลบ เมื่อข้อมูลเปลี่ยน ยอดรวมและสถิติจะคำนวณใหม่
- **แสดงสถานะเซนเซอร์และสิทธิ์** แจ้งเมื่อยังไม่ได้อนุญาตการตรวจจับกิจกรรม กำลังรอค่าตั้งต้น หรือเครื่องไม่มีเซนเซอร์

## วิธีใช้งาน

1. เปิดแอปที่แท็บ **กิจกรรม** แล้วกด **เริ่มกิจกรรม**
2. หากมีหน้าต่างขอสิทธิ์ **กิจกรรมทางกาย / Physical activity** ให้กดอนุญาต หากขึ้นข้อความรอค่าตั้งต้น ให้เดินเตรียมเล็กน้อย รอเซนเซอร์พร้อม แล้วกดเริ่มอีกครั้ง
3. เดินหรือเขย่าโทรศัพท์ โดยเปิดหน้าจอแอปไว้ จำนวนก้าว จำนวนการเขย่า เวลา และค่าเฉลี่ยจะแสดงระหว่างทำกิจกรรม
4. เมื่อทำเสร็จ หยุดรอให้เซนเซอร์รายงานค่าก้าว แล้วกด **จบและบันทึกกิจกรรม**
5. เปิดแท็บ **ประวัติ** เพื่อดูรายการที่บันทึก แตะรายการเพื่อดูรายละเอียด หรือเลือก **ลบ** และยืนยันการลบ
6. กลับแท็บ **กิจกรรม** เพื่อดูยอดรวม สถิติ และเริ่มรอบถัดไป

เมื่อสลับออกจากแอป ระบบจะพักเวลาและหยุดฟังเซนเซอร์ กลับเข้าแอปแล้วทำรอบเดิมต่อได้ โดยเก็บยอดที่นับแล้วไว้และไม่รวมก้าวที่เดินระหว่างออกจากแอป

## เปิดและรันโปรเจกต์

### สิ่งที่ต้องเตรียม

- Android Studio พร้อม **Android SDK Platform 37**
- ใช้ **Gradle JDK ที่มากับ Android Studio** โปรเจกต์กำหนดภาษา Java 17
- มือถือหรือ Emulator ที่ใช้ **Android 8.0 / API 26 ขึ้นไป**
- การทดสอบเดินจริงต้องใช้มือถือที่มี `TYPE_STEP_COUNTER` และอนุญาตสิทธิ์การตรวจจับกิจกรรม ส่วนการเขย่าใช้ Accelerometer

### รันผ่าน Android Studio

1. Clone repository นี้

   ```bash
   git clone https://github.com/Micosz/CS364Exercise2.git
   ```

2. ใน Android Studio เลือก **Open** แล้วเปิดโฟลเดอร์ `CS364Exercise2` ที่มีไฟล์ `settings.gradle`
3. รอ Gradle Sync เสร็จ และติดตั้ง SDK ที่ Android Studio แจ้งว่าต้องใช้
4. เลือกอุปกรณ์ เลือกโมดูล **app** แล้วกด **Run ▶**

### Build APK และรัน Unit tests

รันคำสั่งจากโฟลเดอร์หลักของโปรเจกต์ โดยตั้ง `JAVA_HOME` ให้ตรงกับ Gradle JDK ที่ใช้

```bash
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

APK สำหรับติดตั้งทดสอบจะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## การทดสอบ

Unit tests ผ่าน **31 กรณี** แบ่งเป็น `StepSessionCounterTest` 12 กรณี, `StepCounterManagerTest` 9 กรณี และ `ShakeDetectorTest` 10 กรณี ครอบคลุมการนับก้าวชุดแรก การเริ่มรอบใหม่ ข้อมูลเซนเซอร์ซ้ำหรือย้อนลำดับ การพักและกลับเข้าแอป สิทธิ์ เซนเซอร์ที่ไม่พร้อม และการป้องกันนับการเขย่าซ้ำ

ทดสอบเปิดแอปและกรณีไม่มีเซนเซอร์นับก้าวบน **Pixel 6a Emulator / API 35** ส่วนคลิปเดโมเป็นการทดสอบบนมือถือจริง **Android 12 / MIUI Global 14.0.2**

| ข้อ | หัวข้อ | การทำงานในแอป |

| 4 | Duration & Average | แสดงเวลา ก้าวต่อนาที และการเขย่าต่อนาที |
| 5 | Total & New Record | แสดงยอดรวม ค่าสูงสุด และสถิติใหม่ |
| 6 | Insert Session | บันทึกข้อมูลเมื่อจบกิจกรรม |
| 7 | Query & Persistence | อ่านประวัติจาก SQLite และเก็บข้อมูลหลังปิดแอป |
| 8 | Delete & Recalculate | ยืนยันก่อนลบ แล้วคำนวณยอดรวมและสถิติใหม่ รวมถึงกรณีลบหมด |

## โครงสร้างโปรเจกต์

โค้ดหลักอยู่ใน `app/src/main/java/th/ac/tu/step/`

| ไฟล์ | หน้าที่ |
| --- | --- |
| `MainActivity.java` | ควบคุมหน้ากิจกรรมและประวัติ การเริ่ม–จบรอบ สิทธิ์ และ lifecycle |
| `StepCounterManager.java` / `StepSessionCounter.java` | รับค่าเซนเซอร์และคำนวณก้าวเฉพาะรอบ |
| `ShakeDetector.java` | ตรวจจับและนับการเขย่า |
| `ActivitySession.java` / `DBHelper.java` | ข้อมูลกิจกรรมและการบันทึก อ่าน ลบใน SQLite |
| `ActivityAdapter.java` | รายการประวัติและหน้าต่างรายละเอียด |
| `SessionPanel.java` / `SessionStats.java` | แสดงเวลา ค่าเฉลี่ย ยอดรวม และสถิติ |

Layout และข้อความอยู่ใน `app/src/main/res/` ส่วน Unit tests อยู่ใน `app/src/test/java/th/ac/tu/step/`
